PROJECT OVERVIEW:
================================================================================
This is a full-stack Java Spring Boot e-commerce web application that enables
users to browse products, manage shopping carts, place orders, and provides
administrative capabilities for managing items, categories, users, and orders.

The application targets multi-user authentication with role-based access control
supporting three authority levels: System Admin (0), Operational Admin (1), and
Regular Customers (2).

Database: Oracle Database (PDBORCL)
Server Port: 55000
Context Path: /shared_shop
Java Version: 17
Spring Boot Version: 3.1.5

DATABASE ENTITIES & RELATIONSHIPS:
================================================================================

USERS TABLE:
  - id (PK)
  - email (UNIQUE)
  - password
  - name
  - postal_code
  - address
  - phone_number
  - authority (0=System Admin, 1=Operator, 2=Customer)
  - delete_flag
  - insert_date

ITEMS TABLE:
  - id (PK)
  - category_id (FK → Categories)
  - name
  - price
  - description
  - stock
  - image (filename)
  - delete_flag
  - insert_date

CATEGORIES TABLE:
  - id (PK)
  - name
  - description
  - delete_flag
  - insert_date

ORDERS TABLE:
  - id (PK)
  - user_id (FK → Users)
  - order_date
  - shipping_address
  - payment_method
  - status
  - total_price
  - delete_flag

ORDER_ITEMS TABLE (Junction):
  - id (PK)
  - order_id (FK → Orders)
  - item_id (FK → Items)
  - quantity
  - unit_price

RECENT JAVASCRIPT ENHANCEMENTS (common.js):
================================================================================

KEY FUNCTIONS:
  1. loadAllItems() 
     - Fetches all items from /items/all API
     - Dynamically creates product cards with HTML
     - Stores data in sessionStorage for persistence
     - Handles image errors with fallback

  2. isLoginPage()
     - Detects if current page is login page
     - Prevents unnecessary API calls on login page

  3. Auto-load on DOMContentLoaded
     - Automatically loads items when page loads
     - Only on non-login pages (checks isLoginPage())

  4. Logo click handler
     - Navigates to home on login page
     - Loads items on other pages

  5. Back-to-top button handler
     - Calls window.history.back()
     - Reloads items after navigation
     - Only on non-login pages

SESSION STORAGE:
  - lastLoadedItems: Stores JSON array of products
  - Persists across page navigation during session

ERROR HANDLING:
  - Image 404 fallback to /images/common/no_image.jpg
  - Cart authorization checking (401 status → redirect to login)
  - API error logging to console

HOW TO USE (FOR AI ASSISTANT):
================================================================================

When injecting Claude AI into this project:

1. QUICK CONTEXT:
   - E-commerce Spring Boot app with Oracle DB
   - Multi-tier architecture (Controller→Service→Repository→Entity)
   - Thymeleaf templating with responsive CSS
   - REST APIs for frontend JavaScript interaction

2. FILE NAVIGATION:
   - Backend logic: src/main/java/jp/co/sss/shop/**
   - Frontend: src/main/resources/templates/ and src/main/resources/static/
   - Config: src/main/resources/application*.properties
   - DB Entities: entity/ folder
   - Controllers: controller/ folder (client/, admin/, login/)

3. COMMON PATTERNS:
   - All controllers return ModelAndView or String (Thymeleaf view name)
   - REST controllers return ResponseEntity<?>
   - Services handle business logic, repositories handle DB
   - Forms use Spring validation with @Valid

4. MODIFICATION TIPS:
   - CSS changes: stylesheet.css (all modern UI in this file)
   - Add new endpoints: Create controller + @RequestMapping
   - Add new entity: Create entity, repository, form, validator
   - Frontend API calls: Modify common.js fetch() functions

5. DEBUGGING:
   - Check application logs for SQL queries
   - Browser console for JavaScript errors
   - Network tab for API call issues
