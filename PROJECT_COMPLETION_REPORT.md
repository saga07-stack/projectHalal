1. Open `forms.css`


### Change Primary Color
```css
:root {
  --color-primary: #your-color;
}
/* All buttons, links, highlights auto-update */
```

### Adjust Form Width
```css
.form-card {
  max-width: 600px;  /* Default 500px */
}
```

### Change Button Style
```css
.btn-primary {
  padding: 16px 24px;  /* Make bigger */
  border-radius: 20px; /* More rounded */
}
```

### Increase Font Size
```css
:root {
  --font-size-base: 16px;  /* Default 14px */
}
```

## 🐛 Troubleshooting

### Issue: Old styles still showing
**Solution:** Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)

### Issue: Thymeleaf not working
**Solution:** Ensure `xmlns:th="http://www.thymeleaf.org"` in HTML root

### Issue: Layout broken
**Solution:** Add viewport meta tag: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`

### Issue: Buttons not aligned
**Solution:** Wrap buttons in `.form-actions` container
