[S-04] SECURITY HEADERS
  - Why it matters
    Browsers can't protect against clickjacking, MIME sniffing, XSS without headers.
  - Where in code
    SecurityConfig.java, NEW HeadersHttpFilter.java (or use Spring Security headers())
  - Steps
    1. In SecurityConfig, configure headers:
       http.headers()
         .frameOptions().sameOrigin()
         .contentSecurityPolicy("script-src 'self'")
         .xssProtection();
    2. Result: Add headers to all responses:
       - X-Frame-Options: SAMEORIGIN (clickjacking)
       - X-Content-Type-Options: nosniff (MIME sniffing)
       - Content-Security-Policy: script-src 'self' (XSS)
       - Strict-Transport-Security: max-age=31536000 (HTTPS only)
    3. Test: inspect response headers in browser
  - Done when
    All responses have security headers, no MIME sniffing/clickjacking
  - Concept learned
    HTTP security headers, browser protection, CSP, HSTS
  - Difficulty: Easy
